# 📈 Stock Price Prediction using Deep Learning

A deep learning project focused on stock price prediction using LSTM, Attention Mechanism, and Transformer architectures.

## 📌 Project Overview

This project explores deep learning techniques for analyzing historical stock market data and predicting future stock prices.

The project focuses on understanding how different neural network architectures can learn temporal patterns from time-series data.

## 🎯 Objectives

- Analyze historical stock price data.
- Understand time-series forecasting using deep learning.
- Implement LSTM-based prediction models.
- Explore Attention Mechanisms.
- Explore Transformer architectures.
- Evaluate model predictions against actual stock prices.

## 🛠️ Technologies Used

- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- TensorFlow / Keras
- Scikit-learn

## 🧠 Models Explored

### 1. LSTM
Long Short-Term Memory networks are used to learn sequential patterns in historical stock price data.

### 2. Attention Mechanism
Attention helps a model focus on relevant information from different time steps in a sequence.

### 3. Transformer
Transformer architectures use attention mechanisms to learn relationships between elements in sequential data.
